# NujinSkills (`NujinAI`)

Quantitative research, systematic strategy engineering, and autonomous trading repository for **NujinAI**.

## Environment
- **Python Runtime:** `.venv/bin/python` (or `python` when `.venv` is activated)
- **Verification Gate:** `.venv/bin/python -m tools.preflight`
- **Frontend Cockpit:** `frontend/` (managed via `npm` or `.venv/bin/python tools/frontend_control.py`)

## Skill Routing
For any task involving **alpha discovery, feature/indicator engineering, strategy building, backtesting, Cynic auditing, or trading bot operations**, read and follow **[`SKILL.md`](SKILL.md)** as the single source of truth.
